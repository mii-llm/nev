# Historical recipe implementation

These source snapshots preserve the actual experiment code, including selection,
calibration, data generation and translation. MANIFEST.json maps every file back
to its evidence archive. They are reference implementations, not an independent
ready-to-launch project: imports, historical metadata dependencies and LUMI path
assumptions still require a portable wrapper. Do not execute the historical
launchers against a new account without adapting those paths and dependencies.

The packaged inference runtime is already separated under ../runtime.
