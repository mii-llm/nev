# Historical combined GGUF release

The original combined package has been superseded by two public models:

- [Nev GGUF](https://huggingface.co/mii-llm/nev-gguf): standalone decision model; see [its model card](model_cards/nev.md).
- [Nesso3-0.4B-agentic GGUF](https://huggingface.co/mii-llm/nesso3-0.4B-agentic-gguf): standalone generation; see [its model card](model_cards/nesso3.md).

Use the [CPU guide](README.md) for installation, standalone commands and the
combined workflow. No HF login is required. The original combined publication
receipt remains in `results/huggingface-publication.json` as historical evidence.
